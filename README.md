# 📊 Pesquisa de Opinião - TudoWeb

Projeto desenvolvido em **Python** para realizar uma pesquisa de opinião com clientes da empresa fictícia TudoWeb.

## 🎯 Objetivo

O programa coleta informações dos entrevistados para avaliar o grau de satisfação com o atendimento prestado.

Para cada entrevistado, são solicitados:

- Nome
- Idade
- Opinião sobre o atendimento

As opções disponíveis são:

- 1 - EXCELENTE
- 2 - BOM
- 3 - RUIM

Ao final da pesquisa, o sistema exibe:

- Quantidade total de entrevistados
- Quantidade de respostas EXCELENTE
- Quantidade de respostas RUIM

## 🔁 Estruturas utilizadas

O projeto utiliza conceitos estudados em Python, como:

- Estrutura de repetição `for`
- Estrutura de repetição `while`
- Estruturas condicionais `if`, `elif` e `else`
- Operador lógico `or`
- Variáveis e contadores
- Entrada de dados com `input`
- Conversão de valores com `int`
- Formatação de saída com `f-string`

## ✅ Validação

O programa utiliza uma estrutura `while` para impedir o registro de opiniões inválidas.

Caso seja digitado um número diferente de 1, 2 ou 3, o sistema solicita uma nova resposta até que seja informada uma opção válida.

## 🧪 Testes realizados

Foi realizado um teste com **10 entrevistados**, conforme solicitado na atividade.

Resultado do teste:

- Total de entrevistados: 10
- Respostas EXCELENTE: 4
- Respostas RUIM: 3

Também foi testada a validação de uma opção inválida, confirmando o correto funcionamento da estrutura `while`.

## ▶️ Como executar

1. Abra o arquivo `app.py`.
2. Execute o programa com Python.
3. Informe o nome e a idade do entrevistado.
4. Escolha uma das opções de avaliação.
5. Repita o procedimento para todos os entrevistados.
6. Ao final, o sistema exibirá o resultado da pesquisa.
